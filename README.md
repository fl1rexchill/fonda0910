# Приток в фонды денежного рынка (РФ), 2023–2026: данные и эконометрика

Воспроизводимый конвейер: загрузка рядов Мосбиржи и Банка России → помесячная
таблица → регрессии (H1, H2, ARDL, диагностика, устойчивость, структурный
сдвиг) → таблицы и графики для статьи.

## Запуск

```bash
pip install -r requirements.txt
python run_all.py              # загрузить данные и посчитать всё
python run_all.py --skip-fetch # пересчитать по уже скачанным и ручным файлам
```

Результаты:

- `data/processed/dataset.csv` — помесячная таблица (с 2022-06; в модели с 2023-01, колонка `in_model_sample`);
- `data/reconciliation.csv` — сверка потоков Мосбиржи и Банка России;
- `outputs/tables/` — таблицы (CSV + Markdown), статус шагов `model_status.csv`;
- `outputs/figures/` — графики PNG, 300 dpi;
- `outputs/results_summary.md` — краткие результаты для статьи;
- `outputs/data_sources.md` — ряд → источник → URL → дата загрузки → определение, пропуски, сверка, дамми.

## Текущее состояние

Рыночные ряды загружены 2026-10-07 с Мосбиржи (ISS) и Банка России
(`data/raw/*_20261007.*`, журнал — `data/raw/fetch_log.csv`). За 2023-01…2026-09
полны все регрессоры, кроме ставки по вкладам: ЦБ ещё не опубликовал август и
сентябрь 2026 г. Цены биржевых ФДР в этой выгрузке обрываются 19.06.2026, они
нужны только для оценки потока по ΔСЧА. Загрузчик уже исправлен (без
привязки к режиму торгов), повторный `python run_all.py` скачает ряд заново.

Из обзоров Банка России (2023Q1–2026Q2, PDF в `data/raw/cbr_reviews/`) в
`data/manual/cbr_fund_flows.csv` внесены квартальные нетто-притоки по всем
БПИФ, помесячная разбивка за 2024-07…2025-03 и отдельные значения СЧА, каждое
с цитатой. ЦБ не выделяет в этих обзорах поток по фондам денежного рынка,
поэтому эти данные идут в сверку, а не в зависимую переменную.

Нет главного: помесячных нетто-притоков и СЧА фондов денежного рынка за
2023–2026 гг. Их нужно внести в `data/manual/moex_fund_flows.csv` (сводный
ряд Мосбиржи) или как СЧА каждого фонда из раскрытия УК в
`data/manual/fund_nav_monthly.csv` со списком фондов в `data/manual/mm_funds.csv`
(инструкция — `data/manual/README.md`). Пока их нет, регрессии не
оцениваются, и `outputs/results_summary.md` прямо об этом пишет.
Описательные статистики, корреляции, тесты стационарности и VIF регрессоров
уже посчитаны.

## Структура

```
run_all.py            единая точка запуска
src/config.py         период, тикеры, URL, параметры тестов (точка Чоу, HAC-лаги, seed)
src/fetch_moex.py     ISS: RUSFAR, RUSFARIND, IMOEX, G-кривая ОФЗ, цены БПИФ ФДР
src/fetch_cbr.py      ключевая ставка, курсы USD/CNY, ставки по вкладам
src/build_dataset.py  помесячные переменные, оценка потока по ΔСЧА (с флагом), сверка, пропуски
src/models.py         описательные статистики, ADF/KPSS, VIF, H1/H2 (OLS-HAC), ARDL,
                      разности и Энгл–Грейнджер, диагностика, устойчивость, Чоу, Quandt–Andrews
src/plots.py          5 графиков, ч/б-совместимый стиль
src/report.py         data_sources.md и results_summary.md
data/manual/          шаблоны ручного ввода и dummies.csv (включение дамми)
tests/                проверки на синтетике (во временном каталоге) и разборщиков форматов
```

## Проверки кода

```bash
python tests/test_parsers.py    # разбор ответов ISS/ЦБ на образцах формата, без сети
python tests/test_synthetic.py  # весь конвейер на синтетических данных во временном каталоге
```

Синтетические данные создаются только во временном каталоге (переменная
`FDR_WORKDIR`) и в `data/` и `outputs/` проекта не попадают.
