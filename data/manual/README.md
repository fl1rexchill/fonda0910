# Ручной ввод данных

Сюда кладутся ряды, которые нельзя получить автоматически: у источника нет API,
либо сайт недоступен из окружения, где запускается `run_all.py`.

Правила:

- В каждом CSV оставлена только строка заголовков. Заполняйте значениями из
  первоисточника, по одной строке на дату или месяц. Если значения нет,
  строку не добавляйте (пустые ячейки тоже допустимы и читаются как NaN).
- Числа с точкой как десятичным разделителем, без пробелов-разделителей тысяч.
- Месяц: `YYYY-MM`. Дата: `YYYY-MM-DD`. Квартал: `YYYYQn` (например `2025Q3`).
- В колонках `source_title`/`source_url` указывайте конкретный документ
  (пресс-релиз, обзор, xlsx), из которого взято значение.
- Если для ряда есть и автоматическая выгрузка в `data/raw/`, приоритет
  у автоматической. Ручной файл используется, только когда её нет.

## 1. Обязательно вручную: потоки и СЧА фондов

### `moex_fund_flows.csv` — Московская биржа (основной ряд `flow_mm`)

| колонка | содержание |
|---|---|
| `month` | месяц, `YYYY-MM` |
| `category` | `money_market` (рублёвые фонды денежного рынка) или `bond` (облигационные) |
| `flow_bln` | нетто-приток за месяц, млрд руб. (отток со знаком минус) |
| `nav_bln_eom` | СЧА на конец месяца, млрд руб. |
| `source_title`, `source_url` | документ Мосбиржи |
| `note` | выборка фондов, если оговорена в источнике (например «БПИФ и ОПИФ, торгуемые на бирже») |

Где взять: ежемесячные пресс-релизы и обзоры Мосбиржи о рынке биржевых фондов
и фондов денежного рынка (раздел «Новости и пресс-релизы» на moex.com; поиск
по словам «фонды денежного рынка», «БПИФ», «итоги месяца»). Для СЧА отдельных
фондов можно использовать раскрытие УК (ежемесячно, не позднее 13 рабочих
дней после конца месяца). Тогда в `note` перечислите фонды, в `source_url`
поставьте ссылку на раскрытие.

Если есть только СЧА без потоков, оставьте `flow_bln` пустым. Тогда поток
будет оценён как `ΔСЧА − r·СЧА(t−1)` с флагом `flow_is_estimated = 1`.

### `cbr_fund_flows.csv` — Банк России (сверка и `flow_bond`)

| колонка | содержание |
|---|---|
| `period` | `YYYY-MM` для месячных данных или `YYYYQn` для квартальных |
| `period_type` | `M` или `Q` |
| `category` | `money_market` или `bond` |
| `fund_scope` | охват: например `БПИФ`, `ОПИФ`, `БПИФ+ОПИФ`, `все ПИФ` |
| `flow_bln` | нетто-приток за период, млрд руб. |
| `nav_bln_eop` | СЧА на конец периода, млрд руб. |
| `source_title`, `source_url` | документ ЦБ |

Где взять: «Обзор ключевых показателей паевых инвестиционных фондов» и
«Обзор ключевых показателей управляющих компаний» (cbr.ru, раздел
«Аналитика» / «Статистика» → коллективные инвестиции). К обзорам прилагаются
статистические данные в xlsx. Сами xlsx положите в `data/raw/` с датой
загрузки в имени, например `data/raw/cbr_pif_review_2026Q2_20261006.xlsx`.

## 2. Резервные файлы для рядов, которые обычно грузятся автоматически

Заполняйте их, только если автоматическая загрузка не сработала (см.
`data/raw/fetch_log.csv`).

| файл | колонки | первоисточник |
|---|---|---|
| `moex_rusfar.csv` | `date,value` (RUSFAR overnight, % годовых, закрытие дня) | moex.com → Индексы → RUSFAR, выгрузка истории |
| `moex_rusfarind.csv` | `date,value` (значение индекса) | moex.com/ru/index/RUSFARIND (рассчитывается с 31.01.2025) |
| `moex_imoex.csv` | `date,value` (закрытие IMOEX) | moex.com/ru/index/IMOEX |
| `moex_zcyc.csv` | `month,date,y_3m,y_1y` (бескупонная доходность ОФЗ на последний торговый день месяца, % годовых) | moex.com → Кривая бескупонной доходности (G-кривая) |
| `moex_mm_etf_prices.csv` | `date,ticker,value` (цены закрытия LQDT, AKMM, SBMM, TMON) | moex.com, страницы фондов |
| `cbr_key_rate.csv` | `date,key_rate` | cbr.ru/hd_base/KeyRate/ |
| `cbr_fx_usd.csv`, `cbr_fx_cny.csv` | `date,rate` (официальный курс за 1 единицу) | cbr.ru/currency_base/dynamics/ |
| `cbr_dep_rate.csv` | `month,dep_rate,dep_rate_long,series_name,source_url` | cbr.ru → Статистика → Процентные ставки по кредитам и депозитам |

Для `cbr_dep_rate.csv` основной ряд `dep_rate`: средневзвешенная ставка по
вкладам физлиц в рублях сроком до 1 года, кроме «до востребования».
`dep_rate_long`: та же ставка сроком свыше 1 года (необязательно). В колонке
`series_name` запишите точное название ряда и таблицы ЦБ.

## 3. `dummies.csv` — дамми-переменные

`include = 1` включает дамми в модели, `include = 0` выключает. Пики апреля и
июля 2026 г. включены по ТЗ. Регуляторные и налоговые даты по умолчанию
выключены: это предложения, их нужно проверить по указанным официальным
источникам и включить вручную.
